cpl121

The visual language behind the portfolio — colour, type, spacing and components, pulled straight from the codebase. Built to keep every new page on-brand: Web3, VR/3D and OTT, with one teal accent doing the talking.

01

Colour

One accent (teal), neutral grounds that let the work shine, and a theme-aware link colour that keeps 4.5:1 contrast in both light and dark. Everything maps to a semantic token — no raw hex in components.

02

Typography

Three display faces, each with one job. Personality up top, legibility in the body. All three are Google Fonts, self-embedded here so the specimens render true.

Display · hero Welcome Kaushan Script — the hero wordmark only. High character, used once.
Headings · titles Projects & About Architects Daughter — page titles, card headings, section labels.
Body · UI Full-stack developer, VR & OTT. Poiret One — running text and interface copy, 17–18px, line-height 1.7.

04

Elevation & motion

Cards carry a teal ring plus a soft teal glow — depth without heavy drop shadows. Motion is Motion-Driven but restrained: 200–300ms, transform/opacity only, and fully disabled under prefers-reduced-motion.
